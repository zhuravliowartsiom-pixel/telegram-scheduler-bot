# Telegram Scheduler Bot

Telegram-бот на Python для чтения Google Sheets через API,
обработки данных через DeepSeek и рассылки результатов в Telegram-чаты.

## Технологии

- Python 3.11+
- aiogram
- Google Sheets API
- DeepSeek API
- Docker
- GitHub Actions

## Состояние проекта

Начальная настройка репозитория.
